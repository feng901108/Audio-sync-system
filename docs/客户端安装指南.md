# 客户端安装指南（Termux + 原生 snapclient）

## 概述

本方案使用 **Termux + proot-distro(Debian) + snapclient** 替代更新缓慢的 Snapdroid，直接运行 Snapcast 官方原生客户端。

**适用场景：**
- ✅ 安卓手机（有触摸屏，操作 Termux 方便）
- ⚠️ 小米电视（无触摸屏，需要通过 ADB 预配置，详见 TV 专用方案）
- ✅ Mac（直接 Homebrew 安装）

**为什么不用浏览器播放？**
浏览器（Web Audio API）运行在沙箱中，**无法获取硬件级别的精确音频时间戳**，同步精度通常在几十到几百毫秒，无法满足 < 100ms 的严格同步要求。因此播放终端必须使用原生客户端。

## 一、安卓手机方案

### 1. 安装 Termux

**下载渠道：**
- F-Droid（推荐）：https://f-droid.org/packages/com.termux/
- GitHub Releases：https://github.com/termux/termux-app/releases

> **注意**：不要从 Google Play 下载 Termux，Play 商店版本已停止维护。

### 2. 运行一键安装脚本

打开 Termux，执行以下命令：

```bash
# 下载安装脚本
curl -fsSL https://raw.githubusercontent.com/YOUR_REPO/main/scripts/termux-install.sh | bash
```

或者手动执行以下步骤：

#### 2.1 更换国内源（加速下载）

```bash
termux-change-repo
# 选择 "Mirrors in Chinese Mainland" → 中科大或清华源
```

#### 2.2 安装必要组件

```bash
pkg update -y
pkg install -y wget curl proot-distro pulseaudio
```

#### 2.3 安装 Debian 发行版

```bash
proot-distro install debian
```

#### 2.4 进入 Debian 并安装 snapclient

```bash
proot-distro login debian

# 在 Debian 内部执行：
apt update
apt install -y wget pulseaudio

# 下载对应架构的 snapclient（以 arm64 为例）
ARCH=$(dpkg --print-architecture)
VERSION="0.34.0-1"
wget "https://github.com/badaix/snapcast/releases/download/v0.34.0/snapclient_${VERSION}_${ARCH}_bookworm.deb" -O /tmp/snapclient.deb

# 安装
apt install -y /tmp/snapclient.deb

# 退出 Debian
exit
```

#### 2.5 配置 PulseAudio 音频输出

```bash
# 启动 PulseAudio
pulseaudio --start

# 配置 PulseAudio 允许网络连接
export PULSE_SERVER=127.0.0.1
```

#### 2.6 配置 snapclient 自启动

创建启动脚本：

```bash
cat > ~/.snapclient-start.sh << 'EOF'
#!/data/data/com.termux/files/usr/bin/bash

# 启动 PulseAudio
pulseaudio --start 2>/dev/null
sleep 1

# 获取 NAS IP（请修改为您的 NAS 实际 IP）
NAS_IP="192.168.1.100"

# 启动 snapclient
proot-distro login debian -- bash -c "export PULSE_SERVER=127.0.0.1 && snapclient -h ${NAS_IP}"
EOF

chmod +x ~/.snapclient-start.sh
```

**修改 NAS_IP 为您的实际 NAS 局域网 IP。**

#### 2.7 手动启动 snapclient

```bash
bash ~/.snapclient-start.sh
```

### 3. 设置开机自启

#### 方案 A：Termux:Boot（推荐）

1. 从 F-Droid 安装 **Termux:Boot**
2. 创建启动脚本目录：
   ```bash
   mkdir -p ~/.termux/boot
   ```
3. 创建启动脚本：
   ```bash
   cat > ~/.termux/boot/start-snapclient.sh << 'EOF'
   #!/data/data/com.termux/files/usr/bin/bash
   
   # 等待网络就绪
   sleep 10
   
   # 启动 snapclient
   bash /data/data/com.termux/files/home/.snapclient-start.sh
   EOF
   
   chmod +x ~/.termux/boot/start-snapclient.sh
   ```
4. 重启手机后，Termux:Boot 会自动运行该脚本

#### 方案 B：Tasker 自动化（更灵活）

1. 安装 Tasker
2. 创建任务：运行 Shell 命令 `bash ~/.snapclient-start.sh`
3. 设置触发条件：设备启动 / 连接到家庭 WiFi

### 4. 延迟校准

每个设备的音频输出路径延迟不同，需要手动校准：

1. 播放一段有明显节拍的音乐
2. 在 NAS 的 Snapweb 界面（`http://<NAS_IP>:1780`）中
3. 找到该客户端，调整「Latency」参数
4. 建议范围：-200ms ~ +500ms
5. 微调直到两个音箱听感完全同步

## 二、小米电视专用方案（ADB 预配置）

### ⚠️ 重要说明

小米电视**没有触摸屏**，在电视上直接操作 Termux 终端非常困难。因此采用 **ADB 远程预配置** 方案：

1. 在电脑上通过 ADB 连接电视
2. 一键执行安装和配置脚本
3. 配置完成后，电视开机自动启动 snapclient
4. **无需在电视上手动操作终端**

### 前置要求

1. 小米电视开启 **ADB 调试**：
   - 设置 → 关于 → 产品型号 → 连续点击7次「产品型号」开启开发者模式
   - 设置 → 账号与安全 → ADB调试 → 允许
2. 电脑已安装 ADB 工具
3. 电视和电脑在同一局域网

### 一键安装（在电脑上执行）

```bash
# 连接电视（替换为电视的实际 IP）
adb connect 192.168.1.200:5555

# 下载并执行安装脚本
curl -fsSL https://raw.githubusercontent.com/YOUR_REPO/main/scripts/tv-adb-install.sh | bash
```

或者手动步骤：

#### 1. 安装 Termux 到电视

```bash
# 下载 Termux APK
wget https://f-droid.org/repo/com.termux_118.apk -O /tmp/termux.apk

# 安装到电视
adb install /tmp/termux.apk

# 安装 Termux:Boot（用于开机自启）
wget https://f-droid.org/repo/com.termux.boot_1000.apk -O /tmp/termux-boot.apk
adb install /tmp/termux-boot.apk
```

#### 2. 通过 ADB 在 Termux 中执行安装

```bash
# 授予 Termux 存储权限
adb shell pm grant com.termux android.permission.WRITE_EXTERNAL_STORAGE

# 推送安装脚本到电视
adb push scripts/tv-termux-setup.sh /sdcard/Download/

# 在 Termux 中执行脚本
adb shell am startservice -n com.termux/.app.TermuxService -a com.termux.service_execute -d file:///sdcard/Download/tv-termux-setup.sh
```

> 更详细的 TV 安装步骤请参考 `scripts/tv-termux-setup.sh` 脚本。

### 备选：继续使用 Snapdroid

如果您觉得 TV 上的 Termux 方案太复杂，**Snapdroid 仍然是一个简单可靠的选择**：

- 下载：https://github.com/badaix/snapdroid/releases/tag/v0.29.0.2
- 虽然更新慢，但核心功能稳定
- 支持 Android TV 启动器
- 安装简单，操作直观

**建议组合：**
- 手机 → Termux + snapclient（体验最新版本）
- 电视 → Snapdroid（简单可靠）

## 三、macOS 客户端（snapclient）

### 1. 安装

```bash
brew install snapcast
```

### 2. 运行

```bash
# 直接连接
snapclient -h <NAS_IP>

# 指定输出设备
snapclient -h <NAS_IP> -s 2

# 查看可用设备
snapclient -l
```

### 3. 设置开机自启

```bash
cat > ~/Library/LaunchAgents/com.snapcast.snapclient.plist << EOF
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
    <key>Label</key>
    <string>com.snapcast.snapclient</string>
    <key>ProgramArguments</key>
    <array>
        <string>/opt/homebrew/bin/snapclient</string>
        <string>-h</string>
        <string>NAS_IP_ADDRESS</string>
    </array>
    <key>RunAtLoad</key>
    <true/>
    <key>KeepAlive</key>
    <true/>
</dict>
</plist>
EOF

launchctl load ~/Library/LaunchAgents/com.snapcast.snapclient.plist
```

> 将 `NAS_IP_ADDRESS` 替换为实际 IP。

## 五、同步精度验证

### 人耳测试法

1. 播放有清晰鼓点的音乐
2. 将两个音箱放在一起
3. 从不同位置听是否有回声感
4. 如果听不出明显回声，说明同步良好（< 100ms）

### 专业测试法

1. 用两个麦克风分别录制两个音箱
2. 用音频编辑软件对齐波形
3. 测量时间差

## 六、常见问题

### Q: snapclient 启动报错 "Connection refused"？

**A:**
- 确认 NAS IP 地址正确
- 确认 NAS 防火墙开放了 1704 端口
- 确认手机和 NAS 在同一局域网

### Q: 没有声音？

**A:**
- 检查 PulseAudio 是否启动：`pulseaudio --check`
- 检查系统音量是否静音
- 检查 snapclient 音量：在 Snapweb 中查看

### Q: 有声音但不同步？

**A:**
- 检查网络稳定性
- 在 Snapweb 中微调各客户端的 Latency
- 增大服务器缓冲：编辑 `config/snapserver/snapserver.conf`

### Q: Termux 后台被杀？

**A:**
- 关闭电池优化：系统设置 → 电池 → Termux → 不优化
- 使用 Termux:WakeLock 保持运行
- 在 Termux 中执行 `termux-wake-lock`

### Q: 小米电视无法安装 Termux？

**A:**
- 确认已开启「允许安装未知来源应用」
- 尝试通过小米电视助手远程安装
- 备选：继续使用 Snapdroid
